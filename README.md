# БЖУ — питание и активность для iPhone

Готовая статическая PWA для GitHub Pages.

Приложение ведёт дневник питания и БЖУ, считает дневной расход от ходьбы и
тренировок, показывает потреблённые, потраченные и чистые калории. Для силовых
упражнений поддерживаются подходы, повторения, рабочий вес и отдых; для кардио —
время, дистанция, скорость, интенсивность и интервалы бега.

Расход калорий является оценочным. Он рассчитывается по массе тела и MET,
а для силовых упражнений дополнительно учитывает объём и рабочий вес.

## Публикация

1. Создайте публичный репозиторий, например `bju-iphone`.
2. Загрузите содержимое этой папки в корень ветки `main`.
3. GitHub → Settings → Pages → Build and deployment → Source: `Deploy from a branch`.
4. Branch: `main`, Folder: `/(root)` → Save.
5. Сайт будет доступен по адресу `https://<username>.github.io/bju-iphone/`.

## Установка на iPhone

Откройте сайт в Safari → Поделиться → На экран «Домой» → Добавить.

Данные приложения хранятся локально в браузере устройства. Для переноса используйте экспорт/импорт резервной копии внутри приложения.
