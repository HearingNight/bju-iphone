# БЖУ+ — питание, активность и восстановление

Статическая русскоязычная PWA для iPhone. Работает без сервера и аккаунта, хранит данные локально и доступна офлайн.

## Возможности

- дневник калорий и БЖУ с целями и настраиваемым учётом расхода;
- быстрый поиск продуктов, избранное, недавние продукты и порции;
- редактирование записей, отмена удаления, копирование вчерашнего приёма пищи;
- сохранённые блюда для повторного добавления;
- ходьба, кардио, интервальный бег и силовые упражнения по подходам;
- предыдущий результат, шаблоны тренировок и таймер отдыха;
- сон, качество восстановления, готовность, усталость и вес;
- графики и сводка за 7 или 30 дней;
- ориентир калорий по формуле Mifflin–St Jeor;
- проверяемый импорт и экспорт резервной копии JSON.

Расход калорий и расчёт дневной цели являются ориентировочными и не заменяют медицинскую рекомендацию.

## Локальный запуск

Приложение состоит из статических файлов. Для проверки service worker запускайте его через любой локальный HTTP-сервер, а не через `file://`.

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Проверка

```powershell
npm test
npm run check
```

Тесты проверяют миграцию старого состояния, расчёты, нормализацию повреждённых данных, соответствие DOM-идентификаторов и состав офлайн-кэша.

## Публикация на GitHub Pages

Разместите содержимое каталога в корне ветки `main`, затем выберите Settings → Pages → Deploy from a branch → `main` / `root`.

Для установки на iPhone откройте сайт в Safari → Поделиться → На экран «Домой».

Данные находятся в хранилище браузера. Экспортируйте резервную копию перед очисткой Safari или сменой устройства.
